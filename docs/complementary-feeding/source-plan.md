## Что берём из таблиц

Шестинедельный план «Мама Ника» и начало 90-дневной таблицы «Росмед» совпадают по первым шести продуктам. Это стартовая очередь, которую родитель сможет увидеть в приложении. Оба материала дают пример порядка, а российские клинические рекомендации оставляют выбор стартового продукта семье и не устанавливают точный интервал между новыми продуктами. [Шестинедельный план и пояснения](https://www.mama-nika.ru/tablitsy-i-shemy-vvedeniya-prikorma-rebyonku-pravila-vvoda-produktov-na-pervye-6-nedel/) · [Таблица на 90 дней](https://rosmed-clinic.ru/articles/pitanie/16653-rekomendatsii-voz-i-skhema-po-vvedeniyu-prikorma-dlya-grudnichkov-tablitsa-na-90.html) · [КР «Пищевая аллергия», раздел 5](https://bazanpa.ru/minzdrav-rossii-klinicheskie-rekomendatsii-ot01012025-h6965575/)

| Очередь из таблиц | Очередь в приложении | Основание |
|---|---|---|
| Кабачок → цветная капуста → брокколи | Тот же порядок | Совпадает в обеих таблицах. |
| Гречневая каша → рисовая каша → кукурузная каша | Тот же относительный порядок | Совпадает в обеих таблицах. |
| В 90-дневной схеме кролик появляется на 64-й день, индейка на 78-й | После гречневой каши добавляем шаг «Источник железа». Кролик, индейка или говядина из подходящих вариантов каталога. Если один из них уже знаком, шаг пройден. | Это адаптация приложения. Российская программа отмечает ценность мяса примерно с 6 месяцев. Место шага в очереди — черновое решение, которое нужно сверить с педиатром. [Программа, гл. 5](https://nczd.ru/wp-content/uploads/2019/12/Met_rekom_1_god_.pdf#page=32) |
| Ежедневные порции, масло в расписании, переходы по неделям | В прототипе храним порядок продуктов. Размер порции, форму, интервалы и рекомендации по аллергенам определяют согласованные общие правила. | В таблицах это часть конкретного меню. Источники и различия по порциям разобраны в [CF-04 и CF-05](knowledge-base.md#карточки-фактов-для-статей-и-подсказок). |

Исходный порядок по обеим таблицам — **кабачок → цветная капуста → брокколи → гречневая каша → рисовая каша → кукурузная каша**. Черновой порядок в приложении вставляет **источник железа между гречневой и рисовой кашей**. Это стартовый маршрут, а точки перехода к общему подбору, в том числе своевременное знакомство с отдельными аллергенами, подлежат медицинской проверке. Возраст сам по себе не означает, что родитель должен пройти стартовый маршрут с начала.

## Как выбирается подсказка

1. Общее правило определяет состояние ребёнка, допуск к новому продукту и возможность продолжить начатое знакомство. При паузе показываем её. Если сегодня уже было знакомство, показываем «На сегодня всё». Если ребёнок уже начал подходящий продукт, предлагаем продолжить, даже если продукт вне плана. Продолжение проходит свои фильтры безопасности.
2. Для свободного дня читаем шаги по порядку. Знакомство засчитывается по статусу конкретного продукта. Для шага «Источник железа» достаточно одного из трёх вариантов. Допустимые варианты поступают из общего слоя фильтров, включая возраст, профиль, исключения и подходящую форму.
3. Выбираем первый незакрытый шаг с подходящим продуктом. Если родитель нажал «Предложить другой», исключаем только эту подсказку на сегодня и пересчитываем выбор. Следующий день снова может начаться с исходного продукта. Завершённый раньше времени шаг второй раз не появится.
4. Если какой-либо продукт временно недоступен, движок ищет следующий допущенный продукт. Приоритет незакрытых шагов сохраняется. При подозрении на реакцию продукт может вернуться только после того, как общий медицинский маршрут допустит его повтор.
5. Когда все шаги закрыты или среди них временно нет подходящих, приложение может перейти к общему подбору, если общий слой допускает рекомендацию. В карточке такого продукта убираем подпись «По плану». При блокирующем состоянии используем действие общего слоя.

| Что произошло | Что увидит родитель |
|---|---|
| Ничего не успели вчера | Следующий шаг по факту записей. Долга по календарю нет. |
| Кабачок и брокколи знакомы, цветная капуста ещё нет | «По плану · Цветная капуста». Брокколи уже засчитана. |
| Цветной капусты нет дома, родитель нажал «Предложить другой» | Следующий допустимый продукт. На следующий день цветная капуста может снова оказаться первой. |
| Гречневая каша и индейка уже знакомы | При закрытых овощных шагах следующей будет рисовая каша. |
| На предыдущий продукт записали реакцию | Общее состояние по реакции имеет приоритет над порядком плана. |
| У семьи уже есть история вне приложения | Можно отметить знакомые продукты в каталоге. Шаги пересчитаются отдельно для каждого ребёнка. |

## Где сравнивать

В существующем движке «По плану» — упорядоченная стратегия для уже отфильтрованных кандидатов. Основа стратегии — версия маршрута с ID каталога, а не копия календаря. Сравниваем с [«Понятными шагами» и другими вариантами](recommendation-draft.md) по понятности следующего шага, порядку первых продуктов, времени до источника железа и поведению при неполных записях. До переноса на Android и iOS нужно согласовать правила старта, границы маршрута и порядок подключения общего подбора. Позиции из старых записей используются по ID каталога.
